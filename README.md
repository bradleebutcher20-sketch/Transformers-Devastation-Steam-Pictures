# Transformers: Devastation — Steam Artwork

A collection of custom Steam artwork and promotional images for **Transformers: Devastation**, designed to give the game a polished, professional appearance in a Steam library.

## About This Repository

This repository contains artwork created and organized for use with **Steam**, including images that can be used to present *Transformers: Devastation* like a fully supported Steam title.

The goal is to provide high-quality, consistent artwork that fits naturally alongside officially released games in a Steam library.

## Artwork

This repository may include:

- Steam library cover artwork
- Library hero/background images
- Game logos
- Horizontal banners
- Promotional artwork
- Custom thumbnails and icons
- Additional Steam-compatible graphics

## Purpose

These images are intended for personal customization of a Steam library and related game presentation.

They can be useful when adding the game as a non-Steam title or when creating a more complete Steam-style presentation for the game.

## Game

**Transformers: Devastation**

Developed by **PlatinumGames** and originally published by **Activision**.
